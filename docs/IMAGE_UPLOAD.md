# v1.2.0 이미지 공고 처리

공고 링크의 공개 이미지 호스트를 DNS/IP 및 리디렉션 단위로 검사하여 다운로드합니다. 사설망 등 비공개 주소는 차단하고 검증한 IP로 직접 연결합니다. HTTPS 인증서 검증을 유지합니다.

직접 업로드는 최대 6장, 장당 12MB, 전체 24MB이며 요청의 순서대로 로컬 OCR을 실행합니다. 이미지 파일의 실제 형식과 해상도를 검사하며 잘못된 base64와 빈 인식 결과는 오류를 반환합니다. 임시 OCR 파일은 처리 후 삭제합니다. GIF/TIFF는 첫 프레임/페이지만 처리합니다.

## 검증

- 자동 테스트 18개: 기존 분석 및 공고 추출, 공개/비공개 DNS, 리디렉션 차단, IP 고정 연결과 TLS 호스트, 파일 형식과 업로드 순서 등.
- 합성 공고 이미지 2장으로 실제 HTTP API와 로컬 OCR 확인: C#, Git, Unity 일치, Docker, Python, Redis 부족.
- 추출 본문 수정 후 재분석 100점, 잘못된 파일 HTTP 400 확인.
- 게임잡 GI_No=284976의 외부 이미지에서 본문 3021자 인식 확인.
- 다른 물리적 PC와 브라우저 클릭 검증은 별도로 실시하지 않았습니다.
