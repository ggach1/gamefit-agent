GameFit Agent - Windows 10/11 x64 portable edition

사용 방법
ZIP 전체를 압축 해제한 뒤 GameFit.exe를 더블클릭하세요.
Python·OCR 엔진·한국어/영어 모델이 포함되어 있습니다.
공고 링크 / 이미지 업로드 / 텍스트 중 선택하고 본인 기술 스택을 입력하세요.
이미지는 최대 6장, 장당 12MB, 합계 24MB이며 표시된 순서로 처리합니다.
GIF는 첫 프레임, TIFF는 첫 페이지만 읽습니다. OCR은 로컬에서 수행됩니다.
OCR 본문을 확인하고 오탈자를 수정한 뒤 재분석할 수 있습니다.
사용 중 검은 콘솔 창을 유지하세요. 종료하려면 창을 닫으세요.
_internal 폴더가 반드시 EXE와 함께 있어야 합니다.
개발자 컴퓨터가 꺼져 있어도 실행할 수 있습니다.
공고 다운로드에는 인터넷이 필요합니다.

1. Extract the WHOLE ZIP to a folder.
2. Double-click GameFit.exe. Your browser opens automatically.
3. Paste a public GameJob recruitment link and enter your skills.
4. Image postings are read with local Korean/English OCR.
5. Check the extracted text; edit it and re-analyze if needed.
6. Keep the console window open while using the app. Close it to stop.

Python, Tesseract, Korean/English models are included in _internal.
Do not move GameFit.exe away from _internal.
No API keys or admin installation are needed.
Internet is needed to download the posting and images, not for OCR.
OCR may misread words. The score is keyword coverage, NOT hiring probability.
If port 8000 is occupied, a free port is chosen automatically.
JobKorea support is limited to pages exposing JobPosting JSON-LD.
Login-required or inaccessible pages may fail. Private image addresses are blocked.
For failures, select image upload (up to 6 images) or direct text input.
